  • 先对用Git管理的文件夹创建远程仓库

  • git submodule add <repository_URL> <path_to_submodule>

    • 先对内层的子文件夹进行Git约束（和远程仓库建立同步映射关系），得到repository_URL。这里是https://github.com/295060456/JobsBlock

    • path_to_submodule 是相对外层Git文件的路径。这里是./JobsBlock

    • 此时会在最外层目录，生成一个名为.gitmodules的隐藏文件

  • 最后，对最外层的Git管理的文件（夹），进行同步处理。成功完成！！！
